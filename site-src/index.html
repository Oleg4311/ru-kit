ru-kit

Русская локаль для JavaScript без зависимостей. Всё ниже считается прямо в вашем браузере той же библиотекой, которую можно поставить в проект. Код и документация на GitHub.

Склонение по числу

«1 яблоко, 2 яблока, 5 яблок, 11 яблок, 21 яблоко».

Число прописью

Целые до 10²¹; род важен для «одна/один/одно».

Сумма прописью

Строка разбирается точно, без ошибок плавающей точки: «1,005» → 1 рубль 01 копейка.

Проверка реквизитов

Проверяется контрольная арифметика, а не существование организации. Попробуйте ИНН 7707083893.

Транслитерация

Паспортная (ГОСТ Р 52535.1), ISO 9 (обратимая) и «для адреса».

Телефон

Приводит запись к «+7» и форматирует.

Длительность

Миллисекунды → «1 час 2 минуты 5 секунд».

Подключение

import { plural, numberToWords, isInn } from 'ru-kit';

plural(5, ['яблоко', 'яблока', 'яблок']); // «яблок»
numberToWords(21, { gender: 'f' });        // «двадцать одна»
isInn('7707083893');                       // true
